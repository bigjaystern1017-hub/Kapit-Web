Five improvements based on real-world testing:
FIX 1 — SCROLLING BANNER: Change the marquee text from 'BE INSUFFERABLE ★' to 'Charisma in your pocket... ★' — keep the same styling and single-play animation.
FIX 2 — PREFETCH ON LOCATION SELECT: The first snap after choosing a location is slow because the API call only starts when the user snaps. Fix this by starting the API call THE MOMENT the user selects a location — not when they snap. When a user taps 'Brooklyn Bridge' or gets their GPS location, immediately fire the fetch request in the background. Store the results in state. By the time they pull the suspender and snap, the facts should already be loaded and the wheel can spin directly into the reveal with no wait. If for some reason the API call hasn't finished by the time they snap, THEN show the spinning teasers as a loading state as before. But in most cases the facts should be pre-loaded.
FIX 3 — WIDER RADIUS + REDUCE DUPLICATES: Update the API prompt to request facts from a wider area. Change the prompt to ask for facts within roughly 10 miles of the coordinates instead of 5 miles. Also add this instruction to the prompt: 'Each factoid must be about a DIFFERENT topic, person, and location. Never repeat a fact you have already given. Spread the facts across different neighborhoods and areas within the radius. Mix hyperlocal facts (about this exact block) with broader area facts (about the surrounding borough or city).' Also increase the number of facts per API call from 5 to 8 so the user gets more variety before needing another API call.
FIX 4 — RANDOM WILDCARD FACTS: Every 3rd or 4th snap should serve a fun wildcard fact that is NOT location-based. Add a counter that tracks how many location-based facts have been served. On every 4th snap, instead of pulling from the location cache, call the API with a different prompt: 'Give me 1 completely random, fascinating, conversation-worthy historical factoid from ANYWHERE in the world. Same rules — weird, surprising, bar-conversation tone, 2-3 sentences.' Label this fact with a special category like 'WILDCARD' or 'FROM THE ARCHIVES' and show the location as 'Somewhere on Earth' or similar. This keeps things fresh and surprising for users who are snapping in the same area repeatedly.

Change the body copy to: 'That loud pack. after dark. unfiltered. facts your HR department will flag. $9.99. your call.'
Change the button text from 'flip to black →' to 'enter invite code →'
Add a small text line above or below the button: 'currently invite-only' in JetBrains Mono, 9px, muted color
